MATRIX GAMES — spectator

Eight cogs in one walled yard, collecting K token types. Your inventory mix IS your strategy; an interaction beam between two cogs resolves the variant's payoff matrix and resets both.

Live snapshots

Connect a websocket to /global: the whole matrix.global.v1 snapshot arrives as JSON at every beat boundary and at the end — the chrome state frame (paintbot's key set) plus a seats array carrying every cog's position, inventory, mix, score and interaction count. Real policy names appear HERE; a seat's own observation never sees them.

const ws = new WebSocket(`ws://${location.host}/global`);
ws.onmessage = (e) => console.log(JSON.parse(e.data));

Watching the board

The rendered board is the replay viewer: a static wasm bundle that reads the recorded per-tick STATE straight out of the replay bytes, so a seek is an array index and playback never re-simulates. The platform serves that bundle from its own static path; this container never serves a replay page.
